# PlumeBudget
Un logiciel de gestion de budget, léger et open source. Conçu en Java avec une base de données SQLite pour tourner efficacement sur tous les PC, même les plus modestes.

**PlumeBudget** est une application de bureau de gestion de budget et de suivi de comptes pensée pour le cercle familial. 

L'objectif est simple : proposer un outil de comptabilité domestique transparent, sans dépendance cloud complexe, et extrêmement léger pour pouvoir tourner sans broncher sur n'importe quel petit PC (sous Windows ou Linux).

## Caractéristiques

* **Léger et autonome :** Développé en Java, s'appuyant sur un fichier de base de données unique (`SQLite`). Idéal pour les configurations modestes ou le matériel recyclé.
* **Multi-plateforme :** Fonctionne de manière identique sur **Linux** et **Windows**.
* **Pensé pour la famille :** Une interface claire et accessible à tous les proches, de la saisie des dépenses courantes au suivi du solde global.
* **Zéro superflu :** Pas de jargon marketing, pas d'abonnements cachés, juste vos comptes sous les yeux.

## 🛠️ Stack Technique

* **Langage :** Java
* **Outil de build :** Maven
* **Base de données :** SQLite (stockage local dans un fichier unique, facile à sauvegarder ou à synchroniser via un dossier partagé / NAS)
* **Interface graphique :** Swing, FlatLaf + XChart (graphiques)
